Стартовый «опасный» код:

Starter "dangerous" code:

function printSorted(items: string[]) {
    items.sort();              // ← мутирует исходный массив!
    items.forEach(x => console.log(x));
}

const cities = ["Стамбул", "Ашхабад", "Ташкент"];
console.log("ДО:", cities);
printSorted(cities);
console.log("ПОСЛЕ:", cities);  // ← массив изменился!

Steps:

  4. Запустите снова. Убедитесь: вывод отсортированный, но исходный cities не поменялся.
