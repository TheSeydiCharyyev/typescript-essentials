1. Массив

1. Array

Массив — упорядоченный список значений одного типа. Индекс с 0.

Array — an ordered list of same-type values. Indexed from 0.

Два синтаксиса (эквивалентны):

Two equivalent syntaxes:

let a: number[]      = [1, 2, 3];   // стандарт
let b: Array<number> = [1, 2, 3];   // generic-стиль

Союз типов: (number | string)[] в скобках.

Union inside: (number | string)[] in parentheses.

Пустой массив: всегда аннотируйте, иначе тип any[] / never[].

Empty array: always annotate, else type is any[] / never[].

const items: string[] = [];   // ✅

3. map / filter / find / reduce

3. map / filter / find / reduce

const numbers = [1, 2, 3, 4, 5];

numbers.map(n => n * 2);              // [2, 4, 6, 8, 10] — преобразовать каждый
numbers.filter(n => n > 2);            // [3, 4, 5]        — оставить подходящие
numbers.find(n => n > 2);              // 3                — первый подходящий (или undefined)
numbers.reduce((acc, n) => acc + n, 0); // 15              — свернуть в одно значение

find возвращает T | undefined — обязательно проверяйте результат.

find returns T | undefined — always check the result.

4. noUncheckedIndexedAccess

4. noUncheckedIndexedAccess

Флаг (включён в нашем конфиге): обращение arr[i] даёт тип T | undefined. TS заставит проверить перед использованием.

The flag (enabled in our config): accessing arr[i] gives type T | undefined. TS forces a check before use.

const cities: string[] = ["A", "B"];
const tenth = cities[100];     // тип: string | undefined

console.log(tenth.length);      // ❌ Object is possibly 'undefined'
if (tenth) console.log(tenth.length);  // ✅
console.log(tenth?.length);     // ✅ optional chaining

5. readonly-массивы

5. Readonly arrays

readonly T[] (или ReadonlyArray<T>) — массив без мутирующих методов. Нельзя push, pop, arr[0] = ....

readonly T[] (or ReadonlyArray<T>) — an array with no mutating methods. No push, pop, arr[0] = ....

Зачем:

Why:

  • В параметрах функций — гарантия «не мутирует»
  • В конфигах и константах
  • Защита от мутации извне
  • In function parameters — "does not mutate" guarantee
  • In configs and constants
  • Protection from external mutation
function logAll(items: readonly string[]) {
    items.forEach(x => console.log(x));
    // items.push("x");  // ❌
}

6. Tuple — массив с фиксированной длиной

6. Tuple — fixed-length array

Tuple — массив с фиксированной длиной и разными типами на каждой позиции.

Tuple — an array with fixed length and per-position types.

let person: [string, number, string] = ["Сейди", 20, "Ашхабад"];

person[0];   // string
person[1];   // number
person[3];   // ❌ нет такого индекса

const [name, age, city] = person;   // деструктуризация работает

Где встретите:

Where you'll meet them:

  • Координаты: [x, y]
  • Возврат нескольких значений: [error, result]
  • Пары ключ-значение из Object.entries()
  • React hooks: const [state, setState] = useState(0)
  • Coordinates: [x, y]
  • Returning multiple values: [error, result]
  • Key-value pairs from Object.entries()
  • React hooks: const [state, setState] = useState(0)

7. Named tuples

7. Named tuples

Имена для позиций — для документации (в рантайме исчезают):

Position names — documentation only (vanish at runtime):

type Point = [x: number, y: number];
type Person = [name: string, age: number, city: string];

VS Code показывает имена в autocomplete — пишите их всегда, когда позиции неочевидны.

VS Code shows names in autocomplete — use them any time positions aren't obvious.

9. as const + массив

9. as const + array

const a = [1, 2, 3];               // тип: number[]
const b = [1, 2, 3] as const;      // тип: readonly [1, 2, 3]

Главный паттерн — «список значений → union-тип»:

Headline pattern — "list of values → union type":

const COLORS = ["red", "green", "blue"] as const;
type Color = typeof COLORS[number];
// type Color = "red" | "green" | "blue"

Один источник правды: и список для рантайма, и union для типов.

One source of truth: a list for runtime AND a union for types.

  • readonly T[] — иммутабельный массив. Используем в параметрах функций по умолчанию.
  • Tuple = массив с фиксированной длиной и типами по позициям.
  • Named tuple: [x: number, y: number] — для документации.
  • В tuple можно: опциональные (?) и rest (...T[]) элементы.

  • Always annotate empty arrays: const items: string[] = [].
  • Functional methods (TS 2026 headline): map, filter, find, reduce.
  • find returns T | undefined — always check.
  • With noUncheckedIndexedAccess: arr[i] → T | undefined.
  • readonly T[] — immutable array. Default in function parameters.

  • Named tuple: [x: number, y: number] — documentation.
