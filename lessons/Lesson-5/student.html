1. Примитивы vs объекты

1. Primitives vs objects

Примитив — простое значение без полей. В JS/TS их 7: string, number, boolean, bigint, symbol, null, undefined. Сравниваются по значению.

Primitive — a simple value with no fields. JS/TS has 7: string, number, boolean, bigint, symbol, null, undefined. Compared by value.

"hello" === "hello"      // true (примитивы по значению)
{ a: 1 } === { a: 1 }   // false (объекты по ссылке)

2. string

2. string

3 типа кавычек: ', ", `. Все дают тип string.

3 quote types: ', ", `. All produce type string.

Template literals (backticks `) — современный способ склеивать строки:

Template literals (backticks `) — modern way to compose strings:

const name = "Сейди", age = 20;
`Привет, ${name}! Тебе ${age} лет.`
// эквивалентно: "Привет, " + name + "! Тебе " + age + " лет."

Базовые методы: .length, .toUpperCase(), .toLowerCase(), .trim(), .includes(x), .slice(a, b), .split(x), .replace(a, b).

Basic methods: .length, .toUpperCase(), .toLowerCase(), .trim(), .includes(x), .slice(a, b), .split(x), .replace(a, b).

3. number

3. number

Единый тип для целых, дробных, отрицательных, шестнадцатеричных:

A single type for integers, decimals, negatives, hex:

18, 3.14, -500, 0xff, 0b1010, 1_000_000

Операторы: +, -, *, /, %, **.

Operators: +, -, *, /, %, **.

Полезное: Math.round, Math.floor, Math.ceil, Math.abs, Math.max/min, Math.sqrt, Math.random, x.toFixed(2).

Useful: Math.round, Math.floor, Math.ceil, Math.abs, Math.max/min, Math.sqrt, Math.random, x.toFixed(2).

Специальные значения: NaN, Infinity, -Infinity. Проверка на NaN — только Number.isNaN(x), потому что NaN !== NaN.

Special values: NaN, Infinity, -Infinity. Check for NaN only via Number.isNaN(x) because NaN !== NaN.

4. boolean

4. boolean

Всего 2 значения: true, false. Операторы: &&, ||, !. Сравнение: всегда === и !==.

Two values: true, false. Operators: &&, ||, !. Comparison: always === and !==.

5. Truthy и falsy

5. Truthy and falsy

В if любое значение приводится к boolean.

In if, any value is coerced to boolean.

6 falsy значений: false, 0, "", null, undefined, NaN. Всё остальное — truthy.

6 falsy values: false, 0, "", null, undefined, NaN. Everything else — truthy.

Ловушки: "0" — truthy (непустая строка). [] и {} — тоже truthy.

Traps: "0" is truthy (non-empty string). [] and {} are also truthy.

6. bigint и symbol — редко

6. bigint and symbol — rare

  • bigint — для очень больших целых: 9007199254740993n. Не смешивается с number.
  • symbol — уникальные ключи: каждый Symbol() ≠ любому другому.
  • bigint — for very large integers: 9007199254740993n. Doesn't mix with number.
  • symbol — unique keys: every Symbol() ≠ any other.

7. Literal types — главное

7. Literal types — the headline

Literal type — тип, описывающий одно конкретное значение: "red", 42, true. Не «вообще строка», а именно эта.

Literal type — a type describing one specific value: "red", 42, true. Not "any string", but exactly that one.

let status1: string = "ok";   // тип: string — любая строка
let status2: "ok" = "ok";     // тип: "ok" — только эта строка

8. Union из литералов

8. Literal unions

Через | перечисляем допустимый набор значений:

Use | to list allowed values:

type TaskStatus = "todo" | "in-progress" | "done" | "archived";

function setStatus(taskId: number, status: TaskStatus) { ... }

setStatus(1, "done");        // ✅
setStatus(2, "Done");        // ❌ опечатка — TS поймал!
setStatus(3, "compleated");  // ❌ опечатка — TS поймал!

Зачем нужно: защита от опечаток, autocomplete в VS Code, самодокументирующийся код.

Why useful: typo protection, autocomplete in VS Code, self-documenting code.

9. as const — заморозка

9. as const — freezing

«Сделай тип максимально точным и сделай иммутабельным»:

"Make the type maximally precise and immutable":

let a = "hello";              // тип: string
let b = "hello" as const;     // тип: "hello"

const config = {
    apiUrl: "https://api.example.com",
    mode: "production"
} as const;
// все поля становятся литералами + readonly

Используется для конфигов, наборов опций, констант. Один из главных инструментов TS 2026.

Used for configs, option sets, constants. One of TS 2026's headline tools.

10. Template literal types (тизер)

10. Template literal types (teaser)

Шаблоны на уровне типов. Подробно — в занятии 26.

Templates on the type level. Details in Lesson 26.

type Greeting = `Hello, ${string}!`;
const g: Greeting = "Hello, World!";   // ✅
const g: Greeting = "Hi, World!";      // ❌

type ClassName = `${"red" | "blue"}-${"small" | "large"}`;
// "red-small" | "red-large" | "blue-small" | "blue-large"
