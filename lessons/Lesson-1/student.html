1. Что такое TypeScript

1. What is TypeScript

TypeScript (TS) — строго-типизированная надстройка над JavaScript, разработанная Microsoft. Добавляет к JS систему типов, которая проверяется ещё до запуска кода. Браузер TypeScript не понимает — каждый .ts-файл сначала компилируется в .js.

TypeScript (TS) is a strongly-typed superset of JavaScript developed by Microsoft. It adds a type system to JS that is checked before the code runs. Browsers don't understand TypeScript — each .ts file is first compiled to .js.

Главная идея: любой валидный JavaScript-код — это уже валидный TypeScript-код. TS только добавляет возможности, ничего не отнимая.

Main idea: any valid JavaScript code is already valid TypeScript. TS only adds features, taking nothing away.

3. Какую проблему решает TypeScript

3. What problem TypeScript solves

JavaScript — динамически-типизированный, переменная может в любой момент сменить тип. Это приводит к скрытым ошибкам:

JavaScript is dynamically-typed, a variable can change type at any time. This leads to hidden bugs:

// JavaScript — БАГ не виден до запуска
function calculatePrice(price, quantity) {
    return price * quantity;
}
calculatePrice("100", 3);  // → "100100100" (строка вместо 300!)

// TypeScript — ошибка видна СРАЗУ в редакторе
function calculatePrice(price: number, quantity: number): number {
    return price * quantity;
}
calculatePrice("100", 3);  // ❌ Argument of type 'string' is not assignable to 'number'

Запоминалка: JS ловит ошибки в проде, TS ловит ошибки в редакторе. Лучше потратить минуту на исправление в редакторе, чем час на отладку в продакшене.

Mnemonic: JS catches bugs in production, TS catches bugs in the editor. Better to spend a minute fixing in the editor than an hour debugging in production.

4. Как работает TypeScript: компиляция

4. How TypeScript works: compilation

┌─────────────┐ tsc ┌─────────────┐ запуск ┌──────────────┐ │ app.ts │ ──────────▶ │ app.js │ ──────────▶ │ Браузер / │ │ (с типами) │ компилятор │ (чистый JS) │ │ Node.js │ └─────────────┘ └─────────────┘ └──────────────┘
  1. Пишем app.ts с аннотациями типов.
  2. Запускаем компилятор: tsc app.ts
  3. Компилятор: а) проверяет типы; б) генерирует app.js без типов.
  4. Запускаем готовый app.js — в браузере или через node app.js.
  1. Write app.ts with type annotations.
  2. Run the compiler: tsc app.ts
  3. Compiler: a) checks types; b) emits app.js without types.
  4. Run the resulting app.js — in the browser or with node app.js.

Важно: аннотации типов (: number, : string, interface) исчезают после компиляции. В браузер попадает чистый JS — типы не «съедают» производительность и ничего не весят.

Important: type annotations (: number, : string, interface) vanish after compilation. The browser receives plain JS — types don't cost performance and add no weight.

6. Первый взгляд на TS-код

6. First look at TS code

// Аннотация типов переменных
let age: number = 18;
let name: string = "Seydi";
let isStudent: boolean = true;

// Типизированная функция
function add(a: number, b: number): number {
    return a + b;
}

// Интерфейс — описание формы объекта
interface User {
    name: string;
    age: number;
    email: string;
}

const seydi: User = {
    name: "Seydi",
    age: 20,
    email: "seydi@example.com"
};
